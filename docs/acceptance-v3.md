# V3 验收记录

日期：2026-09-07。延续 V2 布局与轻量约束，更新已批准的头像、社媒平台、软件图标和动效。

## 已验证

- `pnpm test`：10/10；TypeScript 与生产构建通过。
- 官方资产：10 个品牌图标均加载成功；官方来源、安全检查及哈希见 brand-assets.md。
- 头像：附件原图仅生成 256/512 WebP、180 PNG 与多尺寸 ICO，未生成替代人像；ICO 文件头与解码有效。
- 浏览器：320/390/768/1024/1440 宽度无横向溢出，工具列表未越界。
- 入场：技能与软件条目 320ms，错峰 60ms；图标额外延迟 40ms。滚动后软件条目共入场 6 次，返回该区域不会重播。静止时 running animations 为 0，观察期间没有 long task。
- 光标：普通区域为白色箭头、可交互区域为荧光绿圆形箭头；Tab 后恢复原生光标。独立事件测试涵盖 pointerout、blur、键盘、触摸、减少动态效果、输入框和浏览器滚动条。
- 减少动态效果：运行中动画为 0，自定义光标隐藏，scroll-behavior 为 auto。
- 禁用 JavaScript 后重新加载：内容及官方图标可读，原生项目详情可展开并显示 ROLE/CHALLENGE/SOLUTION。
- 独立审查发现触摸端待补充社媒状态不够明确，已增加常驻文字。未发现其他阻断问题。

## 性能报告及限制

本轮 Lighthouse 13.4.1 手机报告位于上级 test-results/liuling-v3-final-1.json：Performance 100、Accessibility 96、Best Practices 100、SEO 100；LCP 1339.6ms、CLS 0、TBT 0、总传输 71,951 bytes。控制台无错误。

报告已成功写出，但工具在结束清理 Chrome 临时目录时出现 Windows EPERM，命令退出码为 1。补跑专用审计浏览器被自动审批策略阻止，因此不声称补跑通过。此后仅将社媒提示居中、将导航入场位移从 8px 调为 6px、移除未引用旧 favicon；功能与尺寸检查覆盖最终构建。

Accessibility 扣分为用户确认保留的低对比装饰标题，实际标题语义及角色信息均有完整可读文本。最终产物脚本 gzip 1.96KB，CSS gzip 5.99KB；无动效依赖、远程字体或分析 SDK。
